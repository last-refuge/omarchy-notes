# Omarchy Notes Rust 0.1.0 — unreleased candidate

This is a preparation note, not a published stable release. The Rust edition has
its own executable/package (`omarchy-notes-rust`), desktop identity
(`org.omarchy.Notes.Rust`) and preview compatibility launcher. Qt remains the
default installer route. Rust preserves its `omarchy-notes-gpui` data and
preferences locations.

Candidate work includes bounded retained editors, prefix search/sorting,
keyboard folder navigation and persisted view state, recoverable deletion and
prepared imports, portable exports and verified backup routes. The release
evidence ledger determines which workflows have completed acceptance; these
notes do not certify them.

Before a stable tag, replace this candidate note with the exact tested scope,
source revision, supported platform, installation/rollback instructions and
remaining minor limitations. Required human trial/accessibility, full native,
performance, failure, compatibility, installed-package and dependency-license
gates remain open. No stable artifact is authorized by this file.
